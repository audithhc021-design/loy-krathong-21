# แอพกิจกรรมวันลอยกระทงออนไลน์ 2569 (LINE LIFF + Next.js + Supabase)

เว็บแอพแบบ Mobile-first สำหรับจัดกิจกรรมวันลอยกระทงออนไลน์ภายในหน่วยงาน (~200 คน)

## ฟีเจอร์หลัก
- **ลอยกระทง + คำอธิษฐาน (1 คน / 1 กระทง):** ตกแต่งชิ้นส่วนกระทง (ฐาน, ดอกไม้, เทียน, ของแต่ง) พร้อมคำอธิษฐานและแสดงผลบนแม่น้ำจำลองแบบเรียลไทม์
- **โหวตแบบไม่เปิดเผยชื่อเจ้าของ (Anonymous Voting):** ซ่อนชื่อและแผนกเจ้าของกระทงจนถึงวันประกาศผล, ได้สิทธิ์คนละ 3 โหวต (ห้ามโหวตตัวเอง)
- **กติกาเวลาอัตโนมัติ (เวลาไทย UTC+7):**
  - เปิดถึง **24 พ.ย. 2569 เวลา 16:00 น.**: เปลี่ยนใจ/ย้ายโหวตได้
  - **24 พ.ย. 2569 เวลา 16:00 – 24:00 น.**: โหวตที่กดไว้แล้วล็อกถาวร (คนที่ยังใช้ไม่ครบ 3 โหวตยังกดเพิ่มได้)
  - **24 พ.ย. 2569 เวลา 24:00 น.**: ปิดรับกระทง ปิดควิซ และปิดโหวต
  - **25 พ.ย. 2569 เวลา 08:00 น.**: ประกาศผลรางวัลที่ 1–3, รางวัลโดนใจกรรมการ 2 รางวัล, และผู้โชคดี Lucky Draw
- **ควิซรักษ์สิ่งแวดล้อม:** คำถาม 5 ข้อพร้อมเฉลยความรู้ (ตอบซ้ำได้จนกว่าจะถูกครบ 5/5)
- **ภารกิจ 3 ขั้น -> สิทธิ์จับฉลาก:** ส่งกระทง + ผ่านควิซ + โหวตครบ 3 ครั้ง = ได้รับสิทธิ์เข้ากล่องสุ่มอัตโนมัติ
- **เมนูแอดมิน & จับฉลากสดสำหรับผู้อำนวยการ:** รหัสผ่านเริ่มต้นคือ `loykrathong2569` (เปลี่ยนได้ผ่าน `ADMIN_PASSWORD`)

## 1. ทดลองรันบนเครื่องทันที (โหมด Dev ไม่ต้องต่อเน็ต/ฐานข้อมูล)

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` (แนะนำเปิดโหมดมือถือใน DevTools หรือบนมือถือ) ระบบจะใช้ข้อมูลทดสอบใน `.data/local-db.json` ให้ทดลองลอยกระทง โหวต สลับผู้ใช้ ทดสอบควิซ และกดจับฉลากได้เลย

## 2. การขึ้นระบบจริงแบบฟรี 100% (Supabase + LINE LIFF + Vercel)

1. **Supabase (ฟรี ไม่ต้องผูกบัตร):**
   - สร้างโปรเจกต์ใหม่ที่ [supabase.com](https://supabase.com)
   - เปิด **SQL Editor** แล้วคัดลอกไฟล์ `supabase/schema.sql` ไปรัน
   - คัดลอก `Project URL` และ `service_role` key จาก **Project Settings -> API**
2. **LINE LIFF (ฟรี):**
   - เข้า [LINE Developers Console](https://developers.line.biz/console/)
   - สร้าง Provider -> สร้าง **LINE Login** Channel (เปิดใช้งาน scope `profile` และ `openid`)
   - ไปที่แท็บ **LIFF** -> Add LIFF App (Size: `Full`) และใส่ Endpoint URL เป็นโดเมน Vercel ของคุณ
   - นำ `LIFF ID` (เช่น `2001234567-AbCdEfGh`) และ `Channel ID` มาใส่ใน Environment Variables
3. **Vercel (ฟรี ไม่ต้องผูกบัตร):**
   - Push โค้ดขึ้น GitHub แล้ว Import เข้า [vercel.com](https://vercel.com)
   - ตั้งค่า Environment Variables ตามไฟล์ `.env.example`:
     - `NEXT_PUBLIC_LIFF_ID`
     - `LINE_LOGIN_CHANNEL_ID`
     - `NEXT_PUBLIC_SUPABASE_URL`
     - `SUPABASE_SERVICE_ROLE_KEY`
     - `ADMIN_PASSWORD`
   - Deploy แล้วนำ URL ที่ได้ไปอัปเดตใน **LIFF Endpoint URL**
